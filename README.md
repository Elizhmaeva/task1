# Поиск частых наборов: алгоритм Apriori

Практическое задание по дисциплине «Интеллектуальный анализ данных».
Программа находит частые наборы товаров в наборе данных о покупках в супермаркете
с помощью алгоритма Apriori.

## Состав каталога

| Файл | Назначение |
|---|---|
| `apriori.py` | реализация алгоритма Apriori и программа с интерфейсом командной строки |
| `experiments.py` | эксперименты с разными порогами поддержки и построение диаграмм |
| `baskets.csv` | набор данных: 7501 транзакция, 115 товаров |
| `results/experiments.csv` | сводная таблица экспериментов |
| `results/itemsets_XX.csv` | частые наборы и их поддержка для порога XX % |
| `results/time.png`, `results/counts.png` | диаграммы |

## Запуск

Нужен Python 3.8 или новее. Для `apriori.py` сторонние библиотеки не требуются,
для `experiments.py` нужна библиотека matplotlib (`pip install matplotlib`).

```
python apriori.py baskets.csv 0.05 --order support
python apriori.py baskets.csv 0.03 --order lex --output result.csv
python experiments.py
```

Параметры `apriori.py`:

- `dataset` — CSV-файл, в котором одна строка соответствует одной транзакции;
- `min_support` — порог поддержки, доля от 0 до 1 (0.05 соответствует 5 %);
- `--order` — упорядочивание результата: `support` — по убыванию поддержки
  (по умолчанию), `lex` — лексикографическое;
- `--output` — необязательный CSV-файл для сохранения результата.

Пример вывода:

```
Транзакций: 7501, порог поддержки: 0.05
Найдено частых наборов: 28

Поддержка  Набор
0.2384     {минеральная вода}
0.1880     {макароны}
0.1797     {яйца}
...
0.0612     {макароны, минеральная вода}
```
